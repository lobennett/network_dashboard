Connect to the study

You need uv, SSH, and a Sherlock account with read access to the lab’s russpold Oak data. Use a current Chrome browser. No local DataLad, Git, or git-annex installation is needed.

1. Run this on your computer

Replace YOUR_SUNET_ID with your username. Run in Terminal (macOS or Linux; Windows users can use WSL2).

uvx --python 3.12 --from DASHBOARD_ORIGIN/downloads/network_dashboard-0.5.0-py3-none-any.whl network-dashboard connect --ssh YOUR_SUNET_ID@login.sherlock.stanford.edu

Complete Stanford authentication when prompted. The command installs the small service, refreshes the study index, and starts a local connection. Leave the terminal running.

2. Open the dashboard

Go to the dashboard, select Connect to local study, and allow local-network access if Chrome asks. Choose Scans, Surfaces, or Flywheel sources. Select a scan, then use Images & reports to open an image or report.

Files download from Oak when opened and remain cached for future visits. FreeSurfer review offers norm/ribbon overlays and individual white/pial surfaces when the reconstruction and its provenance are available. Fieldmaps and magnitude images appear alongside the session’s other scans.

Next time, updates, and disk space

Run the same command next time. Restart it to refresh the index or renew SSH authentication. Press Ctrl+C to stop. Each connection gets a separate cache under ~/.cache/network-dashboard; the terminal prints the exact path. Existing matching caches are reused; add --cache /path/to/cache to choose a different location. You can delete this cache after stopping the service.

MRIQC report figures may require downloading their result archive on first use. The site displays the index timestamp; it is a snapshot of recorded processing.

Troubleshooting
  • Oak read access denied: your SSH login worked, but a shared file or parent directory is unreadable. Send the reported path to the dataset owner; reinstalling the launcher will not change Oak permissions.
  • SSH authentication denied: check your username and complete Stanford authentication. This is separate from permission to read Oak files.
  • Cache belongs to a different connection: remove any explicit --cache option and use the current command above. Hostname corrections automatically use a separate cache without deleting older downloads.
  • Connection refused: keep the terminal running and permit Chrome’s local-network access. The default local port is 18782.
  • Content differs: restart the command to refresh the index. If this persists, the owner needs to rebuild the shared index.
  • Preview blocked: anatomical images and surfaces require verified defacing provenance; missing evidence must be fixed upstream.

Vercel hosts the interface only. Study data travels from Oak over your SSH connection to your computer. Your credentials stay on your computer.
